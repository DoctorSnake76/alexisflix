# Alexisflix

Le CV d'Alexis Druaux, chef de projet IT & transformation digitale, présenté comme une plateforme de séries.

**Voir le site : https://doctorsnake76.github.io/alexisflix/**

- Intro et choix du profil (Recruteur·euse, Manager pressé·e, Robot ATS, Jury du Nobel, Invité·e LinkedIn)
- 4 saisons d'expérience, 2 spin-offs, un Top 10 des compétences
- Une bande-annonce jouée dans un lecteur maison
- Un épisode interactif façon « choisissez votre fin »
- Une vue ATS en texte brut, mots-clés surlignés
- Les posts LinkedIn présentés comme des documentaires

Un seul fichier `index.html`, sans dépendance ni étape de build : HTML, CSS et JavaScript natifs. Les visuels sont dessinés en SVG dans le code.

## Lancer en local

```sh
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

## Crédits

- Bruitages : [Mixkit](https://mixkit.co/free-sound-effects/), sous la [licence Mixkit Sound Effects Free](https://mixkit.co/license/#sfxFree). Ils sont chargés depuis le CDN de Mixkit au moment de la lecture et ne sont pas redistribués dans ce dépôt.
- Polices : Google Fonts (Anton, Archivo Black, Bebas Neue, Inter, Playfair Display, Space Mono), sous licence SIL Open Font License.
- Parodie faite main, sans lien avec une plateforme de streaming existante.
